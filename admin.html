新增条目

保存只写到浏览器本地草稿，点「下载 works-data.js」覆盖文件后才会影响主页。
字段规则：title ≤30 字；link 必须 http(s) 开头；keywords ≤5；category 只能是 文章/视频（一字不差）。
草稿自动存在浏览器 localStorage，关页面不丢；换电脑请记得先导出文件。
打开方式：项目目录下 npm run dev 后访问 http://localhost:5173/admin.html（自动载入现有数据），或直接双击本文件再点「导入数据文件」。
